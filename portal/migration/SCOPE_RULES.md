# Scope Rules

- Platform contains portal authentication, administrators, authorization, sessions, security settings, and cross-scope audit controls.
- absustaininvest.com contains corporate submissions, communications, and ventures.
- cash-clip.app contains product operations, financial controls, integrations, publisher operations, support, and web operations.
- shared/database/users contains shared identity records only.
- sandbox contains unclassified legacy files and settings.
- Files migrate one at a time after review and approval. Bulk merges are prohibited.
