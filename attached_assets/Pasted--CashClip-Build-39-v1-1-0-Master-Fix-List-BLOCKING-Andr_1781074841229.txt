🟡 Issue 4 — Motorola G Layout Too Wide
Cause: NativeAdCard.native.tsx line 7 captures screen width once at import time.
Fix — change lines 7–8:


// BEFORE
const { width: SCREEN_WIDTH } = Dimensions.get("window");
export const CARD_WIDTH = (SCREEN_WIDTH - 48) / 2;

// AFTER — move inside component, use hook
import { useWindowDimensions } from "react-native";
// inside NativeAdCard component:
const { width: SCREEN_WIDTH } = useWindowDimensions();
const CARD_WIDTH = (SCREEN_WIDTH - 48) / 2;
(Note: CARD_WIDTH can no longer be a module export — pass it as a prop or compute inline)
