## Screenshot Capture Plan

The screenshots should be produced from a TestFlight/internal-testing build. If you use a review account, pre-load it with a non-zero balance and at least one completed transaction. Use the following frame guidelines:

- **Devices**: iPhone 16 Pro Max simulator (6.9"), iPhone 14 Plus (6.5"), Pixel 7 Pro (Android phone).
- **Background**: Use the in-app dark theme (`#0A0A0F`) — no marketing chrome on the first set; add a marketing overlay (headline + subhead) on a second branded variant if time permits.
- **Headline copy** (per screen, optional overlay):
  1. "Earn cash, every day"
  2. "Watch your balance grow"
  3. "Cash out to PayPal in minutes"
  4. "Play and get paid"
  5. "Invite friends, earn together"
- **Output**: place final assets in `artifacts/cashclip/store-assets/ios/` and `artifacts/cashclip/store-assets/android/` (folders to be created when assets land — currently gitignored placeholders).
